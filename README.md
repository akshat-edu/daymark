# Daymark

Daymark is a lightweight exam-preparation workspace built around a few useful habits: make a plan, protect focus time, track syllabus work in more than one stage, and learn from test mistakes.

## How to run

1. Download and unzip the folder.
2. Open `index.html`.
(don't worry your data is not going anywhere, it is scored locally on your browser itself!!!)


## What is Daymark

- A tool where you can setup all your daily tasks, focus totals, syllabus overview, and weekly bars.
- Class 11 and Class 12 chapter matrices, with class and subject filters + separate lecture, practice, and revision checkboxes.
- Switch between dark mode and light mode.
- Focus timer with focus/short-break/long-break modes and completed-session logging.
- Mock test logger and a mistake notebook for noting down your mistakes.
- Weekly planner.
